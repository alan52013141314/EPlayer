# PR-003：播放器操作與視窗配置

## 需求
- 修正浮動歌名重複 tooltip；超長歌名定時捲讀右側內容，尾端停留後回到開頭。
- 主程式與浮動播放器採圓形操作按鈕；播放為向右三角形、設定為齒輪。
- 浮動播放器新增返回主視窗；進入浮動模式隱藏主視窗，音訊繼續。
- 設定使用獨立視窗，主視窗隱藏時仍可開啟。
- 精簡模式單行保留歌名、上一首、播放／暫停、下一首、設定、關閉及返回。
- 音樂庫／播放清單移至可調整寬度的左側欄。
- 主程式移除原生標題列，提供自訂拖曳、最小化、最大化／還原與關閉。

## 實作計劃
1. 建立共用圓形圖示按鈕與受裁切的歌名跑馬燈，消除重複提示來源。
2. 統一主視窗／浮動模式切換，將設定移至獨立 viewport，重排精簡模式。
3. 改造主視窗標題列與左側可調面板，維持既有音訊與清單行為。
4. 執行格式、編譯、單元測試與靜態檢查；實際檢視深淺色、長歌名、浮動返回、獨立設定及單行模式。
5. 更新操作文件、驗收記錄及免安裝套件。

## 範圍與驗收
不新增伺服器或 YouTube 功能。清單列、選單項目、輸入框維持文字閱讀形式；操作按鈕使用圓形。浮動關閉按鈕也會返回主視窗，避免只剩隱藏程式。既有 Windows 10、多螢幕、遊戲覆蓋等未完整實測限制繼續明列。
