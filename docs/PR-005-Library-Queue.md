# PR-005：音樂庫直接播放與清單編輯不中斷

## 需求與決定
- 音樂庫雙擊預設直接播放選取歌曲，不加入／保存到播放清單。
- 設定提供「雙擊音樂庫時加入播放清單」選項，預設關閉；原有＋按鈕仍明確加入清單。
- 加入或移除其他曲目不得重開正在播放的歌曲或清空有效音訊緩衝。
- 使用者確認：移除正在播放的曲目時立即播放下一首；清空清單則停止。

## 工作計劃
1. 用實際音訊引擎重現清單編輯引發的 epoch／token 重建。
2. 區分臨時單曲播放與播放清單來源，設定持久保存，播完重播仍使用原來源。
3. 保留有效解碼器與緩衝，更新曲目索引並排除被刪除的預讀曲目；當前歌曲刪除才切歌。
4. 驗證清單新增／刪除／排序、暫停、清空、歌曲結尾預讀以及設定相容性，執行十分鐘背景耐久與封裝。

## 完成與驗收
- 需求與上述計劃已完成，版本 1.2.0。
- 19 項單元測試、clippy、GUI 行為、50 次清單編輯回歸、4 種播放模式及 300 次 seek 通過。
- 最終 600 秒背景長測通過，20 次清單編輯、31 次載入、5 次掃描，零 underrun。詳見 ACCEPTANCE.md。
