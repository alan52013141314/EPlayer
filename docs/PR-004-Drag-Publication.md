# PR-004：未選曲提示、浮動拖曳修正與公開發布

## 需求
1. 未選曲提示改為「未選取任何音樂」。
2. 修正浮動播放器快速拖曳時在兩個位置間閃動；主視窗現有拖曳行為正常。
3. 完成後發布至公開 GitHub 儲存庫。

## 計劃
1. 建立拖曳與延遲視窗座標的可重播檢查，定位位置命令是否互相覆蓋。
2. 統一使用原生視窗拖曳；區分位置設定請求與系統回報的實際位置，保留位置保存與重設。
3. 執行回歸測試、靜態檢查及桌面拖曳驗收，封裝 1.1.1。
4. 準備可獨立建置的公開來源，排除使用者設定、音樂、資料庫、原始驗收資料與本機產物；保留必要的 eframe 修補來源及授權文字。
5. 以現有 GitHub 帳戶建立公開 EPlayer 儲存庫，推送來源並發布免安裝套件。

不新增其他播放功能或伺服器；不修改使用者舊版本的設定。
