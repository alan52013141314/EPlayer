## 效能與相容性限制

- 既有 release 完整浮動播放器＋歌詞＋頻譜 30 秒取樣：平均總 CPU 約 0.57%，工作集約 177.5 MiB；全部視窗隱藏的 15 秒取樣：平均總 CPU 約 0.123%，工作集 136581120 bytes。這些是本機短取樣，不代表其他硬體或所有負載的保證。
- 後續不再操作使用者桌面，未驗證項目不冒稱通過。原生浮動視窗不注入遊戲，獨佔全螢幕可能遮擋 overlay。
- Windows 10 x64 保留支援目標，實機／虛擬機驗收已由使用者免除。Windows 11 測試在既有開發電腦；移除工具 PATH 不等於全新安裝 Windows，也不證明所有硬體相容。
- 音訊裝置變更或拔除後需重啟播放器。ADTS AAC 的來源延遲／填補可能保留；不任意刪除來源靜音。

## 耐久測試判準與歷史

有效通過需執行滿 600 秒、最終 status=passed、underruns=0，暖機後工作集增長小於 64 MiB，期間音訊輸出持續、混合格式輪播、EQ／FFT 切換及背景掃描。此診斷不包含可見原生視窗渲染，不能代替 GUI 驗收。

- attempt1：180 秒內出現一次 underrun，未通過。
- attempt2：7200 秒、44 次 underrun，未通過；保留歷史失敗，不能與新測試混算。
- attempt3：最後 2940 秒零 underrun，但程序中斷且沒有終態，不算通過。
- candidate5 十分鐘背景測試：600 秒、109 次載入、5 次掃描、零 underrun，暖機後工作集增加 999424 bytes；正常退出。
