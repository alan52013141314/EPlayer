# PR-001：EPlayer 產品需求

日期：2026-10-22  
狀態：本機 1.0 已交付；未完整實測限制經使用者接受；YouTube 尚未開始  
專案位置：`EPlayer/`  
文件性質：本機產品需求文件

## 1. 目標與已確認邊界

建立可以在 Windows 10／11 64 位元本機執行的 Rust 桌面音樂播放器，名稱為 EPlayer。採免安裝版，可以附帶必要的外部工具；本機播放不依賴網路。效能優先，UI 不應拖慢播放或不必要地占用資源。

參考千千靜聽的緊湊播放器形式；深色與淺色各為獨立 preset，預設深色。支援一般桌面介面、置頂迷你播放器與獨立浮動歌詞。

允許分階段完成。1.0 包含下列本機功能；所有 YouTube 播放相關工作在 1.0 之後才處理。初始階段只整理需求及 plan；使用者後續已授權完成除 YouTube 以外的程式。不建立伺服器。

## 2. 1.0 功能與驗收

| ID | 需求 | 驗收條件 |
|---|---|---|

| F02 | 格式支援 | MP3、FLAC、WAV、AAC／M4A、OGG 都有可重複執行的樣本測試；格式細分見下節。 |
| F03 | 基本控制 | 播放／暫停、上一首／下一首、拖曳進度、音量可用；主視窗與浮動模式同步。 |
| F04 | 播放順序 | 隨機播放、單曲循環、清單循環可切換；狀態清楚呈現。 |
| F05 | 播放清單 | 可建立、編輯、排序、刪除清單及清單項目、儲存；重開程式可還原。移除項目不刪除音樂檔案。 |
| F06 | 音樂庫與搜尋 | 掃描使用者指定資料夾；顯示音樂庫並搜尋歌名、歌手、專輯及檔案名；掃描時仍可播放。 |

| F10 | 無縫播放 | 支援可正確辨識邊界的連續曲目；使用連續訊號分割樣本檢查無額外靜音、重複或漏失；限制須記錄。 |
| F11 | Windows 控制 | 系統匣可控制及還原播放器；全域快捷鍵與鍵盤媒體鍵可控制播放；快捷鍵衝突有提示。 |
| F12 | 桌面 UI 與主題 | 原生桌面圖形介面，參考千千靜聽；深色為首次啟動預設，可切換淺色並記憶選擇。 |
| F13 | Overlay 迷你播放器 | 完整／精簡 preset、置頂、拖曳、縮放、透明度、滑鼠穿透及恢復操作均可用，詳見第 4 節。 |
| F14 | 獨立浮動歌詞 | 不依賴主視窗顯示，可與迷你播放器共存；可調位置、大小、透明度及穿透。 |
| F15 | 音訊視覺化 | 隨正在播放的實際音訊變動，可開關；停用後停止分析工作與視覺化專用重繪。 |

## 3. 格式範圍

「全部需要」指先前列出的 MP3、FLAC、WAV、AAC／M4A、OGG，不代表承諾所有音訊格式及所有容器／編碼組合。

開發驗證矩陣至少包含 MP3 CBR／VBR、FLAC、WAV PCM 16／24 位元與浮點、AAC-LC 的 ADTS 檔、M4A 內的 AAC／ALAC、Ogg Vorbis／Opus。後述細分是為涵蓋副檔名常見內容而制定的技術驗證範圍，不是額外產品功能。

不支援、加密或損壞檔案須有明確錯誤，不能令播放器崩潰或卡住。實作時若選定解碼器未涵蓋上述樣本，優先評估隨附解碼補充工具，不能默默縮減已確認的格式。

## 4. 顯示模式與 preset

主題 preset 與佈局 preset 分開，使用者可以組合，例如「淺色＋精簡」。

| 佈局 | 內容 | 行為 |
|---|---|---|
| 主視窗 | 播放資訊、控制、清單、音樂庫及設定入口 | 正常桌面操作；可切換為浮動模式。 |
| 完整浮動播放器 | 歌名／檔案名、歌手、封面、播放控制、歌詞、可選頻譜 | 可置頂、移動、縮放、調透明度、切換滑鼠穿透。 |
| 精簡浮動播放器 | 歌名／檔案名＋播放控制 | 以小面積為優先，保留相同浮動操作；不強制顯示封面、歌詞或頻譜。 |
| 獨立浮動歌詞 | 同步 LRC 歌詞 | 可獨立開關，主視窗隱藏後仍存在，與迷你播放器共用同一播放時間。 |

浮動控制至少包含上一首、播放／暫停、下一首；完整模式提供進度與音量。主視窗縮小／隱藏不應連帶隱藏使用者已開啟的浮動視窗。

滑鼠穿透開啟前，必須有已成功註冊的恢復操作快捷鍵；系統匣亦提供解除穿透及還原視窗入口，避免無法操作。位置與大小需要考慮 DPI、多螢幕及螢幕拔除，重開後不可永久落在不可見區域。

一般桌面應用上的置頂屬必要條件。覆蓋全螢幕遊戲是盡力支援項目：分別測試視窗化、無邊框全螢幕及獨佔全螢幕，記錄實際結果，不承諾所有遊戲可用。1.0 以一般 Windows 浮動視窗實現，不加入遊戲程序注入或 hook 的實作範圍。

## 5. 音訊視覺化定義

使用者描述的是「隨音樂上下跳動」的效果。本計劃採頻譜柱狀圖作為第一版具體呈現：橫向為不同頻率區域，柱高代表該區域的訊號強度，可採對數／dB 刻度；這不是麥克風量測的環境音量。

若只顯示整體左右聲道的音量，通常稱為電平表；本次不另外擴充成多種視覺化模式。頻譜應使用播放器自身音訊資料，不需麥克風或系統錄音權限，不可用無關的隨機動畫代替。

開關狀態需儲存。效能優先的規劃預設為關閉，完整模式及主視窗可開啟；此預設屬設計決策，可於 UI 檢視時調整。所有會顯示頻譜的視窗都隱藏時，暫停分析與動畫更新。

## 6. 效能與資料要求

- 音訊輸出不等待 UI、資料夾掃描、封面處理或頻譜分析。
- 長清單採可見區域繪製；封面縮圖及解碼緩衝有上限，不把整個音樂庫載入記憶體。
- 沒有動畫或資料變動時避免持續高頻重繪；頻譜關閉須減少實際工作。
- 清單、音樂庫索引、主題、浮動視窗設定及等化器設定可持久保存。
- 免安裝模式規劃將資料放在程式旁的 `data` 資料夾；資料夾不可寫時提供錯誤與搬移提示，不要求管理員權限。
- 正確性以斷網、長時間播放、快速切歌、seek、損壞檔案及視窗切換等情境驗證。
- 效能數值由 T1 建立可重現基準；現階段沒有測量結果，不宣稱資源占用已達標。
