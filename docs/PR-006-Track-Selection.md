# PR-006：曲目多選與右鍵清單操作

## 需求
- 音樂庫與播放清單支援一般單選、Ctrl+A 全選、Shift 點擊範圍選取及 Ctrl 點擊增減選取。
- 右鍵已選曲目保留整批選取；右鍵未選曲目改選該列。
- 右鍵可將選取曲目依顯示順序加入指定既有清單，或輸入名稱建立新清單並加入。
- 右鍵曲目可在 Windows 檔案總管開啟所在資料夾並選取該檔案。
- 保留雙擊播放、既有單曲操作及播放中編輯不中斷的行為。
- 使用者確認：音樂庫 Ctrl+A 選取全部搜尋結果（跨頁）；新增「顯示全部搜尋結果」選項，保留分頁模式。

## 工作計劃
1. 建立可測試的列選取狀態；分離選取高亮與目前播放標記，避免文字輸入中的 Ctrl+A 被攔截。
2. 串接兩種列表的多選及右鍵選單；加入目標清單與新建名稱操作。
3. 在資料庫 worker 以交易追加曲目，保留目標清單原內容與順序；同步正在播放的目標清單，不重建音訊。
4. 實作檔案總管定位並處理檔案不存在等失敗。
5. 測試選取、清單交易與 UI，建置並封裝新版本；記錄驗收結果。


## 追加：手動下一首忽略隨機播放
- 使用者回報：隨機播放＋清單循環時，按下一首仍順序切歌。
- 計劃：實際音訊引擎連續手動切歌重現；讓 Next 遵循隨機設定，保留關閉隨機時的順序切歌；回歸驗證。

## 完成與驗收
- 1.3.0 已完成本文件需求與追加的隨機下一首修正。
- 21 項單元測試、clippy、桌面操作與正式版音訊回歸通過。
- 600 秒背景耐久：31 次載入、20 次清單編輯、5 次掃描、零 underrun；測試範圍與限制見 ACCEPTANCE.md。
