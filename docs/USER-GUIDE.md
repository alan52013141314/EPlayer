# EPlayer 使用說明

Windows 10／11 64 位元本機音樂播放器。實際測試環境目前為 Windows 11 build 26200；Windows 10 實機測試依使用者要求省略。此版不含 YouTube。

## 開始使用

將整個 ZIP 解壓到可寫入的資料夾，再開啟 eplayer.exe。保留旁邊的 tools 資料夾；不用安裝 Rust 或另外安裝解碼器。請勿直接從 ZIP 內執行。

「加入音樂」可選取多個檔案，也可將音樂檔拖到主視窗，或將檔案路徑作為啟動參數。支援 MP3、FLAC、WAV、AAC／M4A、Ogg Vorbis／Opus；實際可播放性仍取決於檔案內容是否完整。

按播放／暫停、上一首／下一首，拖動進度條跳轉；音量獨立於 Windows 系統音量。可選不循環、單曲循環、清單循環，並切換隨機播放。

## 清單與音樂庫

輸入清單名稱後按「新增」；選取既有清單可改名、儲存或刪除。預設「我的音樂」保留。清單項目的右鍵選單可播放、調整順序或移除；移除只改清單，不刪除原始檔案。

「掃描資料夾」建立本機音樂庫；搜尋標題、演出者、專輯或路徑，以分頁顯示結果。按曲目旁的「＋」加入目前清單。新增音樂後按「重新掃描」。來源搬移或刪除後，請重新選取有效檔案。

設定和音樂庫儲存在執行檔旁的 data 資料夾。備份時請先關閉 EPlayer，再複製整個 data；播放清單引用原始音樂路徑，搬動音樂後需重新加入。

## 歌詞與浮動模式

同名 LRC 會自動載入，例如 song.flac 搭配 song.lrc；也可按「載入 LRC」。支援時間標籤、多時間標籤、offset，以及 UTF-8、含 BOM 的 UTF-16，舊編碼採 Big5／GBK 偵測。舊編碼若顯示錯字，請另存為 UTF-8。

「浮動播放器」會隱藏主視窗，音樂繼續播放；左側返回箭頭或浮動關閉鍵可恢復主視窗。獨立歌詞可同時開啟。齒輪開啟獨立設定視窗，可在主視窗隱藏時選擇完整或精簡模式，調整視窗不透明度及置頂（文字與按鈕會一起淡化）；精簡模式保留歌名／檔案名和播放控制。拖動標題區移動視窗，右下角可調整大小。

滑鼠穿透開啟後，滑鼠會操作底下的視窗。按 Ctrl＋Alt＋L 恢復主視窗並解除兩個浮動視窗的穿透；恢復快捷鍵註冊失敗時不允許啟用穿透。位置異常可在浮動設定重設位置和大小。

按「縮至系統匣」可隱藏主視窗，浮動視窗繼續運作；雙擊系統匣圖示或按恢復快捷鍵回到主視窗。系統匣選單也提供播放控制和結束。主視窗關閉按鈕會結束程式。

置頂採一般 Windows 視窗機制；獨佔全螢幕遊戲可能遮住浮動視窗，可嘗試遊戲的無邊框視窗模式。程式不會注入遊戲。

## 主題、音效與頻譜

預設深色，主視窗右上角可切換深淺 preset。「等化器」提供 10 段 EQ、前級及開關；提升頻段時降低前級，避免音訊峰值被截斷。「重設為平坦」清除頻段調整。

「頻譜」開關顯示隨歌曲變化的柱狀圖：橫向表示頻率，高度表示該頻帶的相對能量。這不是麥克風音量計，也不是實際環境的聲壓 dB。關閉後停止 FFT 分析。

無縫播放保留來源音訊的自然靜音。有損來源需要可靠的延遲／padding 資訊；原始 ADTS AAC 可能含來源填補樣本，程式不任意裁剪。

## 快捷鍵

| 快捷鍵 | 功能 |
|---|---|
| Ctrl＋Alt＋Space | 播放／暫停 |
| Ctrl＋Alt＋←／→ | 上一首／下一首 |
| Ctrl＋Alt＋L | 恢復主視窗、解除穿透 |
| 鍵盤媒體播放／上首／下首鍵 | 對應播放控制 |

快捷鍵若已被其他程式占用，主視窗會提示。若音訊裝置在執行途中變更或拔除，先確認 Windows 的預設輸出裝置，再重新啟動 EPlayer。

## 測試狀態

目前版本為 1.1.1，YouTube 尚未實作。背景驗收採 10 分鐘混合格式靜音播放，並檢查掃描、EQ、頻譜及切歌；完整結果見隨附「驗收報告.md」。

已知驗證限制：實體媒體鍵、真實多螢幕／不同 DPI、遊戲上方顯示、完整系統匣操作與滑鼠穿透仍未完整實測，使用者已同意明列限制後交付。這些功能已實作，不能解讀為所有裝置或遊戲均已驗證通過。

Windows 10 x64 為支援目標，使用者已免除其實機／虛擬機測試。Windows 11 的既有桌面測試與背景測試均於開發電腦進行；中文／空白路徑及移除開發工具 PATH 已檢查，但未使用全新安裝的 Windows 環境。未完成的拖放及手動 LRC 路徑別名 GUI 回歸亦列為未驗證；路徑別名已有自動測試。

## 1.0.1 外觀

程式圖示改用使用者提供的月面播放圖，介面同步採夜紫／月白兩種配色；首次啟動仍為深色。原有音樂庫、播放清單與設定資料可繼續使用。

## 1.0.2 排版

按鈕與間距統一，長歌名會以省略號顯示，可停留滑鼠查看完整文字；獨立長歌詞同樣處理。主視窗最小尺寸為 680×560，完整浮動模式至少 340×300、精簡模式至少 340×110；等化器頻段在窄視窗可左右捲動。

## 1.1.0 視窗與按鈕

主視窗使用自訂標題列，可拖曳移動，雙擊最大化／還原；右上方依序為最小化、最大化／還原、關閉。右下角可調整主視窗大小。音樂庫與播放清單位於左側，拖曳分隔線調整寬度。

操作按鈕改為圓形，停留可查看名稱；播放為向右三角形、設定為齒輪、清單改名為鉛筆、主題切換為月亮。左側清單及選單項目保留文字。精簡浮動為單行，含返回、歌名、上一首、播放／暫停、下一首、設定及關閉。超長浮動歌名停留 2 秒後向後捲讀，尾端停留 1.5 秒再回到開頭；只顯示一個完整歌名提示。

升級時先關閉舊版，將原有 data 資料夾複製到新套件的 eplayer.exe 旁，可保留音樂庫與設定。

## 1.1.1 修正

沒有載入歌曲時顯示「未選取任何音樂」。浮動播放器及歌詞窗改用 Windows 原生拖曳，避免快速拖曳時被舊座標拉回；位置保存及設定中的位置重設仍保留。
